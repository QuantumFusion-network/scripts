# Quantum Fusion Scripts

Collection of blockchain testing and monitoring tools for QuantumFusion network.

## Projects

### 🔗 Chain Load Test
Load testing tool for measuring blockchain performance and TPS (Transactions Per Second).

**Features:**
- Load balancing scenarios
- TPS measurement
- Network stability testing

**Location:** `chain-load-test/`

### 📊 TPS Monitoring Tool
Advanced TUI dashboard for real-time blockchain monitoring and stress testing.

**Features:**
- Real-time TPS visualization
- Interactive TUI dashboard
- Process management
- CSV export capabilities
- Memory usage monitoring

**Location:** `tps-monitoring/`
